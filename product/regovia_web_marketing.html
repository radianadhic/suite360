Enterprise Regulatory Reporting

Satu platform untuk seluruh kewajiban pelaporan bank kepada regulator.

REGOVIA menyatukan pelaporan OJK (APOLO), Bank Indonesia (ANTASENA/LBUT dan LLD), dan LPS (SCV) dalam satu alur kerja maker–checker–releaser yang diaudit penuh — dari kalender tenggat, produksi dan validasi file, paket terenkripsi bertanda tangan, hingga evidence vault. Dibangun di atas stack gratis dan open source yang handal.

Mengapa REGOVIA

Kepatuhan yang tersebar mahal harganya

Sanksi POJK 22/2025 mencapai Rp100.000 per kesalahan isian (maksimal Rp10 juta per laporan), di luar risiko teguran hingga penurunan penilaian tata kelola. REGOVIA menghilangkan celah-celah utamanya.

🗓️

Tenggat dan PIC tersebar

Puluhan laporan dengan frekuensi dan tenggat berbeda (harian H+1, bulanan tgl 7/15/21, SCV tgl 10) dipantau manual lewat spreadsheet.

  • Regulatory Calendar + Alert Inbox otomatis
  • Matriks PIC & backup PIC per kewajiban
🧾

Format dan validasi rawan salah

Nama file, struktur data, dan aturan validasi tiap kanal (APOLO/ANTASENA/LLD/LPS) berbeda-beda; satu salah format = laporan ditolak.

  • Validasi berlapis L1–L4 pra-kirim
  • Penamaan file persis skema regulator
🗄️

Bukti audit tidak tersentral

Saat pemeriksaan, bukti tanda terima dan jejak perubahan data sulit direkonstruksi dari email dan folder bersama.

  • Evidence Vault WORM + SHA-256 per file
  • Audit trail setiap aksi (siapa, kapan, apa)
Struktur Modul

13 grup modul, satu alur kepatuhan

Dari intelligence regulasi hingga pengiriman bertanda tangan — termasuk trio modul kepatuhan baru: self-assessment pintar, e-KYC dan APU PPT, dan 2FA/MFA-OTP.

BARU · 12.1

Self-Assessment Pintar

40 pertanyaan berbobot × 8 domain → skor maturitas gaya DMAB, radar per domain, rekomendasi otomatis P0/P1/P2, ekspor laporan.

BARU · 12.2

e-KYC dan APU PPT

Verifikasi identitas (NIK/Dukcapil/OCR/liveness — simulasi), screening PEP-sanksi-adverse fuzzy, tier SD/CDD/EDD, STR ke PPATK + CTR ≥ Rp500 jt.

BARU · 12.3

2FA / MFA-OTP

TOTP RFC 6238 (QR, aplikasi authenticator) + OTP-SMS, step-up token 5 menit — wajib untuk kirim laporan, restore, & STR (HTTP 428).

Keamanan dan Kepatuhan

Dibangun dengan kontrol perbankan, bukan sekadar fitur

Diverifikasi security-scan.sh — 21 pemeriksaan black-box PASS, plus 38 uji modul kepatuhan.

🔐

TLS & API murni

Backend HTTPS (HTTP polos ditolak 400), frontend terpisah, header keamanan lengkap.

🔑

Kredensial kuat

PBKDF2-HMAC-SHA256 210k iterasi, lockout 5×→15 menit, sesi 12 jam.

📱

2FA / MFA-OTP

TOTP RFC 6238 + OTP-SMS; wajib untuk transaksi keuangan (POJK 21/2023).

👥

RBAC & SoD

Maker–Checker–Releaser–Admin; pendaftar ≠ pemutus; 403 otomatis lintas peran.

🕶️

Masking PDP

CIF/nama/NIK tersamar untuk non-ADMIN (UU PDP 27/2022).

🗄️

Vault & integritas

File WORM + SHA-256, versi lama superseded tak pernah dihapus.

💾

Backup / DRP

Otomatis 6 jam + on-demand; COPY 12 tabel + manifest; restore transaksional.

📜

Audit trail

Setiap login, generate, approve, submit, STR tercatat (aktor, waktu, detail).

Teknologi

Stack utama: gratis, open source, handal

Tanpa biaya lisensi — sesuai rekomendasi §4.2 dokumen spesifikasi. Komponen berbayar hanya sebagai alternatif opsional bila bank sudah memilikinya.

⚛️

Frontend

React 18 + TypeScript + Ant Design 5 + AG Grid Community + Recharts — build Vite, code-splitting per vendor.

☕

Backend

Java 21 LTS (Temurin) + Spring Boot 3 + OpenPDF — API murni HTTPS, JWT-style token HMAC + cookie CHIPS.

🐘

Database

PostgreSQL 16 — skema metadata-driven (layout laporan dikonfigurasi, bukan hard-code).

Opsional produksi (tetap OSS): Keycloak (SSO/MFA), MinIO/Ceph/SeaweedFS (WORM), Apache Airflow (orkestrasi), Superset (BI), Prometheus+Grafana+Loki (observability), OpenBao (secrets).

Roadmap

Dari prototipe teruji ke produksi terkendali

Program infrastruktur & organisasi (enkripsi at-rest, DC/DRC Indonesia + uji DRP formal, unit & playbook insiden siber + pelaporan OJK, pentest independen psl 23–25, program PDP utuh) dilaksanakan setelah data naik ke server produksi — sesuai keputusan 14 September 2026.

Fase 0 — Prototipe fungsional ✅ (selesai)

13 grup modul, 98 katalog, paket APOLO bertanda tangan, 2FA/MFA, e-KYC dan APU PPT, self-assessment pintar, backup/DRP, scan 21/21 + uji modul 38/38 PASS.

Fase 1 — Fondasi produksi (0–3 bulan)

Sertifikat CA + HSTS, enkripsi at-rest (TDE/vault/backup) + KMS/HSM, SSO Keycloak OIDC, penempatan DC/DRC di Indonesia, formalisasi DRP + uji pemulihan pertama.

Fase 2 — Penguatan siber (3–9 bulan)

WAF + API gateway, SIEM/SOC, playbook & unit insiden siber + pelaporan OJK, pentest independen pertama, program PDP (ROPA, retensi, DPO), pemisahan environment fisik.

Fase 3 — Optimasi (9–18 bulan)

Pelaporan maturitas siber tahunan ke OJK, tanda tangan PSrE tersertifikasi, HA multi-AZ + DR drill berkala, otomasi kalender regulasi end-to-end.
